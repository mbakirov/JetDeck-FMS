# Мир (World, эпик E03)

Модуль World моделирует среду, в которой летит самолёт: время UTC, атмосферу, ветер, магнитное склонение и высоту рельефа. Модуль выполняется первым в шаге. Он считает значения в точке самолёта предыдущего шага и пишет их в секцию `world`. Остальные модули читают эту секцию в том же шаге.

## Где лежит код

| Место | Что внутри |
|---|---|
| `Kernel/Earth/UTCTime.swift` | Календарь UTC без системных часов, десятичный год |
| `Kernel/Earth/Geodesy.swift` | Геодезия WGS-84: прямая и обратная задачи, расстояние до линии пути |
| `Kernel/Earth/Atmosphere.swift` | ISA, отклонение температуры, QNH |
| `Kernel/Earth/AirData.swift` | Пересчёт CAS, Mach и TAS |
| `Kernel/Earth/Wind.swift` | Вектор ветра, профиль ветра по слоям |
| `Kernel/Earth/MagneticModel.swift`, `WMM2025Coefficients.swift` | Модель WMM2025 |
| `Kernel/WorldState.swift` | Секция `world` и неизменная среда сценария `WorldEnvironment` |
| `World/WorldModule.swift` | Сборка секции на каждом шаге |
| `CGeodesic` | `geodesic.c` из GeographicLib-C v2.2 без изменений (MIT) |

Функции лежат в `Kernel`, а не в `World`. Их вызывают и другие модули: Sensors (воздушные параметры), Aircraft (ветер, плотность), FMS (геодезия, склонение в точках плана). Модули не могут импортировать друг друга.

## Входные данные

Данные приходят из `InitialConditions`. Они входят в запись полёта. Версия контракта: 3.

| Поле | Значение |
|---|---|
| `utcStartDate`, `utcStartSecondsOfDay` | Дата и время UTC на шаге 0 |
| `aircraft` | Позиция и геометрическая высота над уровнем моря на шаге 0 (ft) |
| `destinationAirport` | Идентификатор ICAO аэродрома назначения |
| `weather.qnhHPa` | QNH аэродрома назначения |
| `weather.isaDeviationC` | Отклонение температуры от ISA, одинаковое на всех высотах |
| `weather.windLayers` | Слои ветра: высота над уровнем моря (ft), истинное направление «откуда», скорость (kt) |

Позицию на шаге 0 записывает `SimState(initial:)`. Пока в E04 нет модели движения, заглушка Aircraft позицию не меняет.

## Секция `world`

Единицы СИ: Па, К, кг/м³, м/с, м. Углы в градусах.

| Поле | Что это |
|---|---|
| `environment` | Неизменная среда сценария. Создаётся на первом шаге |
| `utc` | Дата, целые секунды суток и доля секунды на конец шага |
| `air` | Давление, температура, плотность, скорость звука и высота по давлению в точке самолёта |
| `wind` | Ветер в точке самолёта (составляющие север и восток) |
| `magneticVariationDeg` | Склонение в точке самолёта, восток положительный |
| `terrainElevationM` | Высота рельефа. В MVP это высота аэродрома назначения |

Поле `environment.destination` хранит результат поиска аэродрома:

- `.found` — аэродром найден;
- `.notInDatabase` — аэродрома нет в базе;
- `.failed` — ошибка чтения базы.

Если аэродром не найден, высота рельефа равна 0 и QNH относится к уровню моря.

## Модели

### Время UTC

Время UTC равно времени старта плюс `step × 0.02 s`. Календарь григорианский, без секунд координации. Переход через полночь меняет дату. `Snapshot.utcSecondsOfDay` считается той же функцией.

### Геодезия

Прямая и обратная задачи на эллипсоиде WGS-84 решаются алгоритмом Карни (`geodesic.c`, GeographicLib-C v2.2, MIT). Погрешность — нанометры. Пеленги истинные, в градусах 0..<360. Константы C-кода задаются при первом вызове. Первый вызов делается один раз, в инициализаторе статической константы. Поэтому параллельные вызовы только читают константы.

Расстояние до линии пути и вдоль неё считается итерациями на эллипсоиде (Baselga, Martínez-Llario, 2018). Начало пути сдвигается вдоль геодезической линии, пока она не станет перпендикулярна направлению на точку. Обычно хватает 2–4 итераций, верхний предел — 20. Знак расстояния: справа от пути плюс, слева минус.

`GeoPoint.distanceNM` из `Kernel/NavData/Geo.swift` считает по сфере. Его использует только пространственный запрос NavDB.

### Атмосфера

- **ISA** (ICAO Doc 7488, U.S. Standard Atmosphere 1976). Тропосфера до 11 000 м с градиентом 6,5 К/км, выше изотермический слой. Модель проверена до 20 км.
- **Отклонение температуры.** T = T_ISA(Hp) + ΔT на всех высотах, где Hp — высота по давлению.
- **QNH** задаёт давление на высоте аэродрома назначения, как в реальности. Высотомер с установкой QNH показывает на аэродроме его высоту при любой температуре. Высота аэродрома по давлению равна его высоте над уровнем моря плюс высота по давлению для QNH.
- **Между аэродромом и другой высотой** работает уравнение гидростатики: dH = (T / T_ISA) · dHp, где H — геопотенциальная высота. Интеграл имеет замкнутую форму. В тёплом воздухе уровень давления выше, чем в ISA, в холодном — ниже.
- **Высота самолёта** геометрическая. Для формул она переводится в геопотенциальную (радиус 6 356 766 м). Обратная задача (высота → Hp) решается методом Ньютона, итераций не больше 8.
- **Высотомер** откалиброван по ISA и показывает Hp(p) − Hp(установка): `Atmosphere.altimeterAltitude`.

### Воздушные параметры

CAS, Mach и TAS связаны формулами Сен-Венана для сжимаемого дозвукового потока. При одной и той же CAS и одном давлении число Mach одно и то же. Поэтому TAS меняется пропорционально квадратному корню из температуры.

### Ветер

Слои сортируются по высоте. Из слоёв с одинаковой высотой берётся первый. Между слоями составляющие север и восток интерполируются линейно. Такая интерполяция корректно проходит через направление 360°. Два противоположных ветра дают штиль посередине. Ниже нижнего и выше верхнего слоя действует крайний слой. Без слоёв — штиль.

### Магнитное склонение

Используется модель WMM2025 (NOAA NCEI, BGS, общественное достояние). Синтез сферических гармоник степени 12 перенесён на Swift по техническому отчёту WMM. Коэффициенты `WMM.COF` записаны таблицей Swift. Тест сверяет её с файлом `Tests/Fixtures/WMM2025.COF`.

Модель действует с 2025.0 по 2030.0. Для даты вне этого интервала используется ближайшая граница. WMM нужна высота над эллипсоидом, а модуль передаёт высоту над уровнем моря. Разница (геоид, меньше 110 м) меняет склонение меньше чем на 0,001°.

### Рельеф

Высота рельефа равна высоте аэродрома назначения из NavDB (`NavAirport.elevationFt`). Модель рельефа по DEM в MVP не входит.

## Проверка

| Критерий приёмки | Тест |
|---|---|
| ISA на контрольных высотах, допуск 0,1 % | `AtmosphereTests.isaMatchesTheStandardTable` (таблица USSA 1976, 0–20 км) |
| QNH ≠ 1013: высотомер на аэродроме показывает его высоту | `altimeterSetToQNHShowsTheElevationOnTheGround` (QNH 980/1013/1040, высоты 0/5434/7820 ft, ΔT −30…+30), `WorldModuleTests.altimeterSetToQNHShowsTheElevationAtTheDestination` |
| ΔT меняет TAS при постоянной CAS | `temperatureDeviationChangesTasAtConstantCas` (CAS 250 kt на FL100: 288,7 kt в ISA, 299,3 kt при ISA +20) |
| WMM совпадает с тестовыми значениями NOAA | `MagneticModelTests`: 12 точек отчёта WMM2025 и 100 точек пакета коэффициентов. X, Y, Z в пределах 0,001 нТл, склонение в пределах 0,01° |
| Геодезия: 10 м и 0,01° | `GeodesyTests`: эталоны из тестового набора Карни (`geodtest.c`). Тесты используют допуск 1 мм и 1e-6° |
| Ветер: интерполяция и крайние слои | `WindTests` |
| Рельеф = высота аэродрома из базы | `WorldModuleTests.terrainIsTheElevationOfTheDestinationInTheDatabase` (KBTV, 335 ft из фрагмента CIFP) |
| Одинаковый вход — одинаковый результат | `WorldModuleTests.sameInputGivesTheSameWorld` |

Время шага с модулем World (`make bench`, 30 000 шагов): в среднем 3,7 мкс при бюджете 20 мс.
